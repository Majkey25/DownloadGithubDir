Privacy and cookies

The app sends the repository, revision and folder you request directly from your browser to GitHub. Public file downloads use raw.githubusercontent.com. If you enter a personal access token, it is sent to api.github.com to authenticate your requests. The token is held in page memory, cleared from the field when a download completes, fails or is canceled, and never saved by the app. ZIP files you save remain on your device until you delete them.

This app has no accounts, analytics, advertising, cookies or persistent browser storage. JavaScript libraries are served with the site, without a third-party CDN request. Do not enter credentials into the repository URL. Use a read-only token limited to the repository you need.

GitHub Pages hosts the site and logs visitors' IP addresses for security. GitHub also receives your API and file requests. Its retention, international transfers and privacy rights are described in the GitHub privacy statement. See also GitHub Pages data collection.
